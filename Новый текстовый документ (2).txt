Шаг 3: Запустить сбор данных на завтра
Важно: сборщик работает только в торговую сессию MOEX (10:00–18:45 МСК). Завтра утром:

Отключить сон (чтобы компьютер не заснул):

powershell
cd C:\ai-advisor
.\keep_awake.ps1
Запустить сборщик:

powershell
venv\Scripts\activate
python collectors\orderflow_fixed.py
Оставить на 2–3 часа (потом Ctrl+C).

Вернуть настройки питания:

powershell
.\restore_power.ps1
Пересобрать и переобучить:

powershell
python collectors\merge_pipeline.py
Copy-Item C:\ai-advisor\combined_data.csv C:\ai-advisor\data\combined_data.csv -Force
python -m src.train_of
python -m src.backtest_of
